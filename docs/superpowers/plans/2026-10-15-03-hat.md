# «Ломаем Лёд» — Plan 3: Шляпа Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Playable team «Шляпа»: players → editable teams → word source (dictionary / own / mix) → 3 rounds (words, gestures, one word) over the same word set, timed turns with guess/skip, last-word grace, editable turn review, carry-over time between rounds, final scores and replay.

**Architecture:** Pure logic modules (`teams`, `words`, `state` reducer) tested with seeded RNG; the reducer is driven by `tick` actions from a 100 ms interval in the screen, so time logic is fully unit-testable. Game state is plain JSON persisted under `KEYS.hatGame` on every change. Views are small phase components switched by `state.phase`.

**Tech Stack:** as Plan 1.

**Spec:** `docs/spec.md` §7. **Depends on:** Plan 1 and Plan 2 Task 1 (`src/lib/random.ts`: `Rng`, `mulberry32`, `range`, `shuffle`).

## Global Constraints

- Russian UI only; dictionary has no 18+ words.
- Minimum 4 players, at least 2 teams, at least 2 players per team.
- Teams: random split + manual fix (tap a player to move them to the next team), auto names (Пингвины, Кактусы…), renamable, each team has a color.
- Teams take turns in a cycle; inside a team the explainer rotates every team turn; the rest of the team guesses.
- Words: dictionary (count 30/40/60 + difficulty easy/medium/hard/mix), own words (each player privately enters K words, default 5), or mix (own + dictionary top-up to count). All 3 rounds use the same word set; the hat is refilled each round.
- Rounds: 1 «Объясняем словами» (no same-root words), 2 «Показываем жестами», 3 «Одно слово».
- Turn: «Объясняет Имя (Команда)» → «Старт» → 3-2-1 → timer (30/45/60/90, default 60) → «Угадали» (+1) / «Пропуск» (word back to hat; −1 if penalty on, default off) → time up: sound + vibration, last attempt for current word (default 5 s, 0 = off) «Угадали» / «Не успели» → review list where mis-taps can be fixed → «Передать ход».
- Hat emptied mid-turn → the round ends; leftover time carries over: the same team and explainer start the next round with the remaining seconds.
- After round 3: final scores, winner (or tie), «Сыграть ещё» (same teams, fresh words) / «В меню».
- Game state persisted under `KEYS.hatGame`; removed on finish.
- Git commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Hat empties on the last guess while time remains → round ends immediately, leftover time carries to the same explainer next round (test in Task 4).
2. In review a player un-ticks the word that emptied the hat → the round must NOT end; the word goes back (test in Task 4).
3. App killed / reloaded mid-turn → game resumes at the review of that turn, not a dead timer (test in Task 4).
4. Own-words mode with duplicates across players («кот», «Кот », «кОт») and empty fields → one «кот», no empty words (test in Task 2).
5. Teams of unequal size (3 vs 2) → explainer rotation cycles each team's own members independently (test in Task 4).

```ts
import { range, shuffle, type Rng } from '../../lib/random';

export interface Team {
  id: string;
  name: string;
  color: string;
  players: string[];
}

export const TEAM_NAMES = ['Пингвины', 'Кактусы', 'Еноты', 'Ламы', 'Акулы', 'Совы', 'Ёжики', 'Йети', 'Манулы', 'Тюлени'];
export const TEAM_COLORS = ['#7fe7ff', '#ff7eb6', '#ffd166', '#7cff9e', '#b69cff', '#ff9f5a', '#5ad1ff', '#ff5e7e', '#c3ff5a', '#ffa8e2'];
export const MIN_TEAM_SIZE = 2;
export const MIN_HAT_PLAYERS = 4;

export function maxTeams(playerCount: number): number {
  return Math.max(2, Math.floor(playerCount / MIN_TEAM_SIZE));
}

export function splitIntoTeams(players: string[], teamCount: number, rng: Rng): Team[] {
  const shuffled = shuffle(players, rng);
  const names = shuffle(TEAM_NAMES, rng);
  return range(teamCount).map((i) => ({
    id: `t${i}`,
    name: names[i % names.length],
    color: TEAM_COLORS[i % TEAM_COLORS.length],
    players: shuffled.filter((_, k) => k % teamCount === i),
  }));
}

export function movePlayerToNextTeam(teams: Team[], player: string): Team[] {
  const from = teams.findIndex((t) => t.players.includes(player));
  if (from < 0) return teams;
  const to = (from + 1) % teams.length;
  return teams.map((t, i) => {
    if (i === from) return { ...t, players: t.players.filter((p) => p !== player) };
    if (i === to) return { ...t, players: [...t.players, player] };
    return t;
  });
}

export function renameTeam(teams: Team[], teamId: string, name: string): Team[] {
  return teams.map((t) => (t.id === teamId ? { ...t, name } : t));
}

export function validateTeams(teams: Team[]): string | null {
  for (const t of teams) {
    if (!t.name.trim()) return 'У каждой команды должно быть название';
  }
  for (const t of teams) {
    if (t.players.length < MIN_TEAM_SIZE) return `В команде «${t.name}» меньше двух игроков`;
  }
  const names = teams.map((t) => t.name.trim().toLowerCase());
  if (new Set(names).size !== names.length) return 'Названия команд повторяются';
  return null;
}
```

```ts
import { shuffle, type Rng } from '../../lib/random';
import type { DifficultySetting, WordDifficulty } from '../../settings/settings';

export type WordMode = 'dictionary' | 'own' | 'mix';
export type Dictionary = Record<WordDifficulty, string[]>;

export interface WordSetup {
  mode: WordMode;
  difficulty: DifficultySetting;
  count: number;
  ownWords: string[];
}

export function normalizeWord(word: string): string {
  return word.trim().replace(/\s+/g, ' ').toLowerCase().replace(/ё/g, 'е');
}

export function dedupeWords(words: string[]): string[] {
  const seen = new Set<string>();
  const out: string[] = [];
  for (const raw of words) {
    const word = raw.trim().replace(/\s+/g, ' ');
    const key = normalizeWord(word);
    if (!key || seen.has(key)) continue;
    seen.add(key);
    out.push(word);
  }
  return out;
}

export function pickDictionaryWords(
  dict: Dictionary,
  difficulty: DifficultySetting,
  count: number,
  exclude: string[],
  rng: Rng,
): string[] {
  if (count <= 0) return [];
  const pool = difficulty === 'mix' ? [...dict.easy, ...dict.medium, ...dict.hard] : dict[difficulty];
  const excluded = new Set(exclude.map(normalizeWord));
  return shuffle(pool.filter((w) => !excluded.has(normalizeWord(w))), rng).slice(0, count);
}

// `exclude` = words of the previous game; ignored for the top-up when the
// dictionary is too small to avoid them entirely.
export function buildWordSet(setup: WordSetup, dict: Dictionary, rng: Rng, exclude: string[] = []): string[] {
  const own = setup.mode === 'dictionary' ? [] : dedupeWords(setup.ownWords);
  if (setup.mode === 'own') return shuffle(own, rng);
  const need = Math.max(0, setup.count - own.length);
  const picked = pickDictionaryWords(dict, setup.difficulty, need, [...own, ...exclude], rng);
  const topUp = pickDictionaryWords(dict, setup.difficulty, need - picked.length, [...own, ...picked], rng);
  return shuffle([...own, ...picked, ...topUp], rng);
}
```

```ts
import type { Team } from './teams';
import type { WordSetup } from './words';

export type HatRound = 1 | 2 | 3;
export type HatPhase = 'roundIntro' | 'ready' | 'countdown' | 'playing' | 'lastWord' | 'review' | 'roundEnd' | 'gameEnd';

export interface HatConfig {
  turnSeconds: number;
  skipPenalty: boolean;
  lastWordSeconds: number;
}

export interface TurnEntry {
  word: string;
  guessed: boolean;
  skipped: boolean;
}

export interface HatState {
  config: HatConfig;
  wordSetup: WordSetup;
  teams: Team[];
  scores: Record<string, number>;
  explainerIdx: Record<string, number>;
  words: string[];
  round: HatRound;
  hat: string[]; // hat[0] is the word currently on screen
  teamIdx: number;
  phase: HatPhase;
  remainingMs: number;
  lastWordMs: number;
  carryOverMs: number | null;
  turn: TurnEntry[];
}

export type HatAction =
  | { type: 'beginRound' }
  | { type: 'startCountdown' }
  | { type: 'startPlaying' }
  | { type: 'tick'; ms: number }
  | { type: 'guess' }
  | { type: 'skip' }
  | { type: 'miss' }
  | { type: 'toggle'; index: number }
  | { type: 'confirmTurn' }
  | { type: 'nextRound'; order: string[] }
  | { type: 'restart'; words: string[]; order: string[] };

interface CreateInput {
  teams: Team[];
  words: string[];
  order: string[];
  config: HatConfig;
  wordSetup: WordSetup;
}

export function createHatGame({ teams, words, order, config, wordSetup }: CreateInput): HatState {
  return {
    config,
    wordSetup,
    teams,
    words,
    scores: Object.fromEntries(teams.map((t) => [t.id, 0])),
    explainerIdx: Object.fromEntries(teams.map((t) => [t.id, 0])),
    round: 1,
    hat: order,
    teamIdx: 0,
    phase: 'roundIntro',
    remainingMs: config.turnSeconds * 1000,
    lastWordMs: 0,
    carryOverMs: null,
    turn: [],
  };
}

export function currentTeam(s: HatState): Team {
  return s.teams[s.teamIdx];
}

export function currentExplainer(s: HatState): string {
  const team = currentTeam(s);
  return team.players[s.explainerIdx[team.id] % team.players.length];
}

export function turnScore(entries: TurnEntry[], skipPenalty: boolean): number {
  const guessed = new Set(entries.filter((e) => e.guessed).map((e) => e.word));
  const penalty = skipPenalty ? entries.filter((e) => e.skipped && !e.guessed).length : 0;
  return guessed.size - penalty;
}

function missCurrent(s: HatState): HatState {
  const [word, ...rest] = s.hat;
  if (word === undefined) return { ...s, phase: 'review' };
  return { ...s, hat: [...rest, word], turn: [...s.turn, { word, guessed: false, skipped: false }], phase: 'review' };
}

function passTurn(s: HatState): HatState {
  const team = currentTeam(s);
  return {
    ...s,
    explainerIdx: { ...s.explainerIdx, [team.id]: s.explainerIdx[team.id] + 1 },
    teamIdx: (s.teamIdx + 1) % s.teams.length,
  };
}

// Applies the (possibly corrected) review: guessed words leave the hat,
// everything else is back in it. Empty hat ends the round; leftover time
// stays with the same team and explainer.
function confirmTurn(s: HatState): HatState {
  const guessed = new Set(s.turn.filter((e) => e.guessed).map((e) => e.word));
  const hat = s.hat.filter((w) => !guessed.has(w));
  for (const e of s.turn) {
    if (!guessed.has(e.word) && !hat.includes(e.word)) hat.push(e.word);
  }
  const team = currentTeam(s);
  const scored: HatState = {
    ...s,
    hat,
    turn: [],
    scores: { ...s.scores, [team.id]: s.scores[team.id] + turnScore(s.turn, s.config.skipPenalty) },
  };

  if (hat.length > 0) return { ...passTurn(scored), phase: 'ready' };
  if (s.round === 3) return { ...scored, phase: 'gameEnd' };
  if (s.remainingMs > 0) return { ...scored, phase: 'roundEnd', carryOverMs: s.remainingMs };
  return { ...passTurn(scored), phase: 'roundEnd', carryOverMs: null };
}

export function hatReducer(s: HatState, a: HatAction): HatState {
  switch (a.type) {
    case 'beginRound':
      return s.phase === 'roundIntro' ? { ...s, phase: 'ready' } : s;

    case 'startCountdown':
      if (s.phase !== 'ready') return s;
      return {
        ...s,
        phase: 'countdown',
        remainingMs: s.carryOverMs ?? s.config.turnSeconds * 1000,
        carryOverMs: null,
        lastWordMs: 0,
        turn: [],
      };

    case 'startPlaying':
      return s.phase === 'countdown' ? { ...s, phase: 'playing' } : s;

    case 'tick': {
      if (s.phase === 'playing') {
        const remainingMs = s.remainingMs - a.ms;
        if (remainingMs > 0) return { ...s, remainingMs };
        if (s.config.lastWordSeconds > 0) {
          return { ...s, remainingMs: 0, phase: 'lastWord', lastWordMs: s.config.lastWordSeconds * 1000 };
        }
        return missCurrent({ ...s, remainingMs: 0 });
      }
      if (s.phase === 'lastWord') {
        const lastWordMs = s.lastWordMs - a.ms;
        if (lastWordMs > 0) return { ...s, lastWordMs };
        return missCurrent({ ...s, lastWordMs: 0 });
      }
      return s;
    }

    case 'guess': {
      if ((s.phase !== 'playing' && s.phase !== 'lastWord') || s.hat.length === 0) return s;
      const [word, ...rest] = s.hat;
      const done = s.phase === 'lastWord' || rest.length === 0;
      return { ...s, hat: rest, turn: [...s.turn, { word, guessed: true, skipped: false }], phase: done ? 'review' : 'playing' };
    }

    case 'skip': {
      if (s.phase !== 'playing' || s.hat.length === 0) return s;
      const [word, ...rest] = s.hat;
      return { ...s, hat: [...rest, word], turn: [...s.turn, { word, guessed: false, skipped: true }] };
    }

    case 'miss':
      return s.phase === 'lastWord' ? missCurrent(s) : s;

    case 'toggle':
      if (s.phase !== 'review' || !s.turn[a.index]) return s;
      return { ...s, turn: s.turn.map((e, i) => (i === a.index ? { ...e, guessed: !e.guessed } : e)) };

    case 'confirmTurn':
      return s.phase === 'review' ? confirmTurn(s) : s;

    case 'nextRound':
      if (s.phase !== 'roundEnd' || s.round === 3) return s;
      return { ...s, round: (s.round + 1) as HatRound, hat: a.order, phase: 'roundIntro', turn: [] };

    case 'restart':
      return createHatGame({ teams: s.teams, words: a.words, order: a.order, config: s.config, wordSetup: s.wordSetup });
  }
}

export function restoreHatGame(raw: unknown): HatState | null {
  if (!raw || typeof raw !== 'object') return null;
  const s = raw as HatState;
  if (!Array.isArray(s.teams) || s.teams.length < 2) return null;
  if (!Array.isArray(s.words) || !Array.isArray(s.hat) || !Array.isArray(s.turn) || !s.config) return null;
  // The timer cannot survive a reload: close the interrupted turn into review.
  if (s.phase === 'playing' || s.phase === 'lastWord') return { ...s, phase: 'review' };
  if (s.phase === 'countdown') {
    const full = s.config.turnSeconds * 1000;
    return { ...s, phase: 'ready', carryOverMs: s.remainingMs < full ? s.remainingMs : null };
  }
  return s;
}
```

```tsx
import { useState } from 'react';
import { plural } from '../../lib/plural';
import { Button } from '../../ui/Button';

interface Props {
  players: string[];
  perPlayer: number;
  onDone: (words: string[]) => void;
}

export function OwnWordsEntry({ players, perPlayer, onDone }: Props) {
  const [index, setIndex] = useState(0);
  const [revealed, setRevealed] = useState(false);
  const [collected, setCollected] = useState<string[]>([]);
  const [draft, setDraft] = useState<string[]>(() => Array(perPlayer).fill(''));
  const player = players[index];

  if (!revealed) {
    return (
      <div className="handoff">
        <p className="muted">Передай телефон</p>
        <h2 className="handoff__name">{player}</h2>
        <p className="muted">Остальные не подглядывают 👀</p>
        <Button size="lg" onClick={() => setRevealed(true)}>Я {player}, показать</Button>
        <p className="muted">Игрок {index + 1} из {players.length}</p>
      </div>
    );
  }

  const submit = () => {
    const next = [...collected, ...draft];
    if (index + 1 >= players.length) {
      onDone(next);
      return;
    }
    setCollected(next);
    setIndex(index + 1);
    setDraft(Array(perPlayer).fill(''));
    setRevealed(false);
  };

  return (
    <div className="stack">
      <h2 className="handoff__title">
        {player}, впиши {perPlayer} {plural(perPlayer, 'слово', 'слова', 'слов')}
      </h2>
      {draft.map((word, i) => (
        <input
          key={i}
          className="input"
          aria-label={`Слово ${i + 1}`}
          value={word}
          maxLength={40}
          autoComplete="off"
          onChange={(e) => setDraft(draft.map((w, k) => (k === i ? e.target.value : w)))}
        />
      ))}
      <Button size="lg" disabled={draft.every((w) => !w.trim())} onClick={submit}>Готово, спрятать</Button>
    </div>
  );
}
```

```tsx
import { useState } from 'react';
import { useNav } from '../../app/nav';
import { HAT_WORDS } from '../../content/hatWords';
import { shuffle } from '../../lib/random';
import { KEYS, saveJSON } from '../../lib/storage';
import { PlayerListInput } from '../../players/PlayerListInput';
import { cleanPlayers, rememberPlayers, validatePlayers } from '../../players/players';
import type { DifficultySetting, TurnSeconds, WordCount } from '../../settings/settings';
import { useSettings } from '../../settings/SettingsContext';
import { Button } from '../../ui/Button';
import { Screen } from '../../ui/Screen';
import { Segmented } from '../../ui/Segmented';
import { Slider } from '../../ui/Slider';
import { Toggle } from '../../ui/Toggle';
import { OwnWordsEntry } from './OwnWordsEntry';
import { createHatGame } from './state';
import { MIN_HAT_PLAYERS, splitIntoTeams, validateTeams, type Team } from './teams';
import { TeamsEditor } from './TeamsEditor';
import { buildWordSet, type WordMode, type WordSetup } from './words';
import './hat.css';

type Step = 'players' | 'teams' | 'words' | 'own';
const MIN_WORDS = 5;

const MODE_OPTIONS: { value: WordMode; label: string }[] = [
  { value: 'dictionary', label: 'Словарь' },
  { value: 'own', label: 'Свои' },
  { value: 'mix', label: 'Микс' },
];
const DIFFICULTY_OPTIONS: { value: DifficultySetting; label: string }[] = [
  { value: 'easy', label: 'Лёгкие' },
  { value: 'medium', label: 'Средние' },
  { value: 'hard', label: 'Сложные' },
  { value: 'mix', label: 'Микс' },
];
const COUNT_OPTIONS: { value: WordCount; label: string }[] = [30, 40, 60].map((v) => ({ value: v as WordCount, label: String(v) }));
const TURN_OPTIONS: { value: TurnSeconds; label: string }[] = [30, 45, 60, 90].map((v) => ({ value: v as TurnSeconds, label: `${v}с` }));
const PREVIOUS: Record<Step, Step | null> = { players: null, teams: 'players', words: 'teams', own: 'words' };

export function HatSetupScreen() {
  const { back, navigate } = useNav();
  const { hat } = useSettings().settings;
  const [step, setStep] = useState<Step>('players');
  const [players, setPlayers] = useState<string[]>(['', '', '', '']);
  const [teams, setTeams] = useState<Team[]>([]);
  const [mode, setMode] = useState<WordMode>('dictionary');
  const [difficulty, setDifficulty] = useState<DifficultySetting>(hat.difficulty);
  const [wordCount, setWordCount] = useState<WordCount>(hat.wordCount);
  const [wordsPerPlayer, setWordsPerPlayer] = useState(hat.wordsPerPlayer);
  const [turnSeconds, setTurnSeconds] = useState<TurnSeconds>(hat.turnSeconds);
  const [skipPenalty, setSkipPenalty] = useState(hat.skipPenalty);
  const [lastWordSeconds, setLastWordSeconds] = useState(hat.lastWordSeconds);
  const [error, setError] = useState<string | null>(null);

  const goTo = (next: Step) => {
    setError(null);
    setStep(next);
  };
  const goBack = () => {
    const prev = PREVIOUS[step];
    if (prev) goTo(prev);
    else back();
  };

  const toTeams = () => {
    const err = validatePlayers(players, MIN_HAT_PLAYERS);
    if (err) return setError(err);
    const names = cleanPlayers(players);
    rememberPlayers(names);
    setTeams(splitIntoTeams(names, 2, Math.random));
    goTo('teams');
  };

  const toWords = () => {
    const err = validateTeams(teams);
    if (err) return setError(err);
    goTo('words');
  };

  const start = (ownWords: string[]) => {
    const wordSetup: WordSetup = { mode, difficulty, count: wordCount, ownWords };
    const words = buildWordSet(wordSetup, HAT_WORDS, Math.random);
    if (words.length < MIN_WORDS) {
      setStep('words');
      setError(`Слишком мало слов: нужно хотя бы ${MIN_WORDS}`);
      return;
    }
    const game = createHatGame({
      teams: teams.map((t) => ({ ...t, name: t.name.trim() })),
      words,
      order: shuffle(words, Math.random),
      config: { turnSeconds, skipPenalty, lastWordSeconds },
      wordSetup,
    });
    saveJSON(KEYS.hatGame, game);
    navigate('hat-game', { replace: true });
  };

  return (
    <Screen title="Шляпа" onBack={goBack}>
      {step === 'players' && (
        <>
          <p className="muted">Впишите всех игроков — минимум четверо. На следующем шаге разобьём на команды.</p>
          <PlayerListInput players={players} onChange={setPlayers} />
          {error && <p className="error" role="alert">{error}</p>}
          <Button size="lg" onClick={toTeams}>Дальше</Button>
        </>
      )}

      {step === 'teams' && (
        <>
          <TeamsEditor teams={teams} onChange={setTeams} />
          {error && <p className="error" role="alert">{error}</p>}
          <Button size="lg" onClick={toWords}>Дальше</Button>
        </>
      )}

      {step === 'words' && (
        <>
          <Segmented label="Откуда слова" options={MODE_OPTIONS} value={mode} onChange={setMode} />
          {mode !== 'own' && (
            <>
              <Segmented label="Сложность" options={DIFFICULTY_OPTIONS} value={difficulty} onChange={setDifficulty} />
              <Segmented label="Слов в игре" options={COUNT_OPTIONS} value={wordCount} onChange={setWordCount} />
            </>
          )}
          {mode !== 'dictionary' && (
            <Slider label="Слов от каждого игрока" min={3} max={10} step={1} value={wordsPerPlayer}
              onChange={setWordsPerPlayer} />
          )}
          <details className="setup-options">
            <summary>Настройки партии</summary>
            <Segmented label="Время хода" options={TURN_OPTIONS} value={turnSeconds} onChange={setTurnSeconds} />
            <Toggle label="Штраф за пропуск (−1)" checked={skipPenalty} onChange={setSkipPenalty} />
            <Slider label="Время на последнее слово" min={0} max={10} step={1} value={lastWordSeconds}
              format={(v) => (v === 0 ? 'выкл' : `${v} сек`)} onChange={setLastWordSeconds} />
          </details>
          {error && <p className="error" role="alert">{error}</p>}
          {mode === 'dictionary' ? (
            <Button size="lg" onClick={() => start([])}>Начать игру</Button>
          ) : (
            <Button size="lg" onClick={() => goTo('own')}>Вписать слова</Button>
          )}
        </>
      )}

      {step === 'own' && (
        <OwnWordsEntry players={teams.flatMap((t) => t.players)} perPlayer={wordsPerPlayer} onDone={start} />
      )}
    </Screen>
  );
}
```

```tsx
export function CountdownView({ onDone }: { onDone: () => void }) {
  const [n, setN] = useState(3);
  const fx = useFeedback();
  useEffect(() => {
    if (n === 0) {
      onDone();
      return;
    }
    fx.sfx('countdown');
    const id = window.setTimeout(() => setN(n - 1), 1000);
    return () => window.clearTimeout(id);
    // deps are only `n`: new onDone/fx identities must not restart the countdown
  }, [n]);
  return (
    <div className="countdown" key={n} aria-live="assertive">
      {n > 0 ? n : ''}
    </div>
  );
}

function TimerRing({ remainingMs, totalMs }: { remainingMs: number; totalMs: number }) {
  const r = 52;
  const length = 2 * Math.PI * r;
  const fraction = Math.max(0, Math.min(1, remainingMs / totalMs));
  const secs = seconds(remainingMs);
  return (
    <div className={`timer ${secs <= 10 ? 'timer--low' : ''}`} role="timer" aria-label={`Осталось ${secs} ${plural(secs, 'секунда', 'секунды', 'секунд')}`}>
      <svg viewBox="0 0 120 120" aria-hidden="true">
        <circle className="timer__track" cx="60" cy="60" r={r} />
        <circle className="timer__bar" cx="60" cy="60" r={r} strokeDasharray={length}
          strokeDashoffset={length * (1 - fraction)} transform="rotate(-90 60 60)" />
      </svg>
      <span className="timer__value">{secs}</span>
    </div>
  );
}

export function GameEndView({ state, onReplay, onMenu }: { state: HatState; onReplay: () => void; onMenu: () => void }) {

      <ScoreBoard state={sorted} />
      <Button size="lg" onClick={onReplay}>Сыграть ещё</Button>
      <Button variant="ghost" onClick={onMenu}>В меню</Button>
    </div>
  );
}
```

```tsx
import { useEffect, useReducer, useRef, useState } from 'react';
import { useNav } from '../../app/nav';
import { useFeedback } from '../../audio/useFeedback';
import { HAT_WORDS } from '../../content/hatWords';

import { KEYS, loadJSON, removeKey, saveJSON } from '../../lib/storage';
import { useWakeLock } from '../../lib/useWakeLock';
import { useSettings } from '../../settings/SettingsContext';
import { Button } from '../../ui/Button';
import { Modal } from '../../ui/Modal';
import { Screen } from '../../ui/Screen';
import {
  CountdownView, GameEndView, LastWordView, PlayingView, ReadyView, ReviewView, RoundEndView, RoundIntroView,
} from './HatViews';
import { ROUNDS } from './rounds';
import { hatReducer, restoreHatGame, type HatState } from './state';
import { buildWordSet } from './words';
import './hat.css';

export function HatGameScreen() {
  const { navigate } = useNav();
  const [initial] = useState(() => restoreHatGame(loadJSON<unknown>(KEYS.hatGame, null)));
  if (!initial) {
    return (
      <Screen title="Шляпа" onBack={() => navigate('menu')}>
        <p className="muted center">Нет активной игры.</p>
        <Button size="lg" onClick={() => navigate('hat-setup', { replace: true })}>Новая игра</Button>
      </Screen>
    );
  }
  return <HatGame initial={initial} />;
}

function HatGame({ initial }: { initial: HatState }) {
  const { navigate, back } = useNav();
  const { settings } = useSettings();
  const fx = useFeedback();
  const [state, dispatch] = useReducer(hatReducer, initial);
  const [confirmExit, setConfirmExit] = useState(false);

  useWakeLock(settings.keepAwake);

  useEffect(() => {
    saveJSON(KEYS.hatGame, state);
  }, [state]);

  const ticking = state.phase === 'playing' || state.phase === 'lastWord';
  useEffect(() => {
    if (!ticking) return;
    let last = Date.now();
    const id = window.setInterval(() => {
      const now = Date.now();
      dispatch({ type: 'tick', ms: now - last });
      last = now;
    }, 100);
    return () => window.clearInterval(id);
  }, [ticking]);

  const prevPhase = useRef(state.phase);
  useEffect(() => {
    const prev = prevPhase.current;
    prevPhase.current = state.phase;
    const timeRanOut = prev === 'playing' && state.remainingMs <= 0 && (state.phase === 'lastWord' || state.phase === 'review');
    if (timeRanOut) {
      fx.sfx('timeUp');
      fx.vibrate([200, 100, 200]);
    }
  }, [state.phase, state.remainingMs, fx]);

  const guess = () => {
    fx.sfx('correct');
    fx.vibrate(30);
    dispatch({ type: 'guess' });
  };
  const skip = () => {
    fx.sfx('skip');
    dispatch({ type: 'skip' });
  };
  const replay = () => {
    const words = buildWordSet(state.wordSetup, HAT_WORDS, Math.random, state.words);
    dispatch({ type: 'restart', words, order: shuffle(words, Math.random) });
  };
  const finish = () => {
    removeKey(KEYS.hatGame);
    navigate('menu');
  };

  return (
    <div className="hat-game">
      <header className="hat-game__header">
        <button type="button" className="icon-btn" aria-label="Назад" onClick={back}>←</button>
        <span className="hat-game__round">Раунд {state.round} · {ROUNDS[state.round].title}</span>
        <button type="button" className="icon-btn" aria-label="Завершить" onClick={() => setConfirmExit(true)}>✕</button>
      </header>

      {state.phase === 'roundIntro' && <RoundIntroView round={state.round} onStart={() => dispatch({ type: 'beginRound' })} />}
      {state.phase === 'ready' && <ReadyView state={state} onStart={() => dispatch({ type: 'startCountdown' })} />}
      {state.phase === 'countdown' && <CountdownView onDone={() => dispatch({ type: 'startPlaying' })} />}
      {state.phase === 'playing' && <PlayingView state={state} onGuess={guess} onSkip={skip} />}
      {state.phase === 'lastWord' && (
        <LastWordView state={state} onGuess={guess} onMiss={() => dispatch({ type: 'miss' })} />
      )}
      {state.phase === 'review' && (
        <ReviewView
          entries={state.turn}
          skipPenalty={state.config.skipPenalty}
          onToggle={(index) => dispatch({ type: 'toggle', index })}
          onConfirm={() => dispatch({ type: 'confirmTurn' })}
        />
      )}
      {state.phase === 'roundEnd' && (
        <RoundEndView state={state} onNext={() => dispatch({ type: 'nextRound', order: shuffle(state.words, Math.random) })} />
      )}
      {state.phase === 'gameEnd' && <GameEndView state={state} onReplay={replay} onMenu={finish} />}

      <Modal
        open={confirmExit}
        title="Завершить игру?"
        actions={
          <>
            <Button variant="ghost" onClick={() => setConfirmExit(false)}>Отмена</Button>
            <Button variant="danger" onClick={finish}>Завершить игру</Button>
          </>
        }
      >
        <p>Счёт этой партии будет удалён.</p>
      </Modal>
    </div>
  );
}
```
