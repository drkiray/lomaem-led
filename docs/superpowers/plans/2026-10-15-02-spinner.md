> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Playable «Крутилочка»: name entry, SVG wheel with one sector per player, rigged-but-random-looking arrow that makes every player spin once and answer once per round, 3 depth levels of question/action cards with no repeats.

**Architecture:** Pure, seeded-RNG-testable logic modules (`turns`, `geometry`, `deck`, `state` reducer) plus thin React views. Randomness is computed in event handlers and passed into the reducer as action payloads, so the reducer stays pure and the game state is plain JSON persisted to `localStorage` on every change. The arrow animates via `requestAnimationFrame` writing an SVG `transform` directly (no React re-render per frame).

**Tech Stack:** as Plan 1 (React 18, TS, Vitest, Testing Library).

**Spec:** `docs/spec.md` §6. **Depends on:** Plan 1 (`2026-10-15-01-foundation.md`) fully implemented.

## Global Constraints

- Russian UI only; no 18+ content (no sex, alcohol, explicit topics).
- Players: minimum 2, no hard maximum, soft warning above 30; names required every game (prefill via «Как в прошлый раз»).
- Each sector has its own color from a palette, cycled; adjacent sectors never share a color.
- Font shrinks as sector count grows; labels run along the radius.
- One round = N turns; within a round every player spins exactly once and answers exactly once, never answering their own spin; spin order is random (not clockwise).
- The spinning player's sector is highlighted and pulses; header shows «Крутит: Имя».
- After a round: «Перейти к раунду X+1» or «Ещё круг»; after round 3: «Ещё круг» or «Завершить игру». Level can be switched early via the round indicator (with confirmation).
- 3 levels × ~40 cards, ≈70/30 question/action (setting `actionRatio`, default 0.3); actions address players by name via `{asker}` / `{answerer}`, never seating («сосед слева»).
- No repeats within a game until a level's deck is exhausted; across games unseen cards are preferred (`KEYS.spinnerSeen`).
- Game state persisted under `KEYS.spinnerGame`; removed on «Завершить игру».
- Git commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Exactly 2 players → they simply ask each other; with any N the derangement never self-targets even with a degenerate RNG (test in Task 1).
2. 30+ players → labels stay inside the wheel (tiny font, truncation with «…»), adjacent colors still differ (test in Task 2).
3. Double-tap on the hub during a spin → only one spin/card (guarded by phase + ref; test in Task 7).
4. App reloaded or killed mid-spin → game restores into the card phase instead of a stuck spinner (test in Task 5).
5. Playing more turns than a level has cards → deck reshuffles for that level only instead of crashing or repeating immediately (test in Task 3).

```ts
export type Rng = () => number;

export function mulberry32(seed: number): Rng {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

export function range(n: number): number[] {
  return Array.from({ length: n }, (_, i) => i);
}

export function shuffle<T>(items: readonly T[], rng: Rng): T[] {
  const a = [...items];
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}
```

```ts
import { range, shuffle, type Rng } from '../../lib/random';

export interface Turn {
  asker: number;
  answerer: number;
}

// Sattolo's algorithm: always a single cycle, so never a fixed point.
function sattolo(n: number, rng: Rng): number[] {
  const a = range(n);
  for (let i = n - 1; i > 0; i--) {
    const j = Math.floor(rng() * i);
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}

// Uniform random derangement by rejection (expected ~e tries);
// falls back to Sattolo if the RNG keeps producing fixed points.
export function randomDerangement(n: number, rng: Rng): number[] {
  if (n < 2) throw new Error('Need at least 2 players');
  for (let attempt = 0; attempt < 100; attempt++) {
    const p = shuffle(range(n), rng);
    if (p.every((target, i) => target !== i)) return p;
  }
  return sattolo(n, rng);
}

export function buildRoundTurns(n: number, rng: Rng): Turn[] {
  const answererOf = randomDerangement(n, rng);
  return shuffle(range(n), rng).map((asker) => ({ asker, answerer: answererOf[asker] }));
}
```

```ts
import type { Rng } from '../../lib/random';

export const WHEEL_SIZE = 400;
export const WHEEL_CENTER = 200;
export const WHEEL_RADIUS = 190;

export const SECTOR_COLORS = [
  '#7fe7ff', '#ff7eb6', '#ffd166', '#7cff9e', '#b69cff', '#ff9f5a',
  '#5ad1ff', '#ff5e7e', '#c3ff5a', '#ffa8e2', '#66ffe0', '#ffb86b',
];

export function normalizeDeg(deg: number): number {
  return ((deg % 360) + 360) % 360;
}

export function sectorAtRotation(rotation: number, n: number): number {
  return Math.floor(normalizeDeg(rotation) / (360 / n)) % n;
}

// Final arrow rotation: at least `extraTurns` full turns, ending at a random
// point inside the target sector (never within 10% of its borders).
export function computeStopRotation(current: number, target: number, n: number, rng: Rng, extraTurns: number): number {
  const size = 360 / n;
  const targetAngle = target * size + size * (0.15 + 0.7 * rng());
  return current + extraTurns * 360 + normalizeDeg(targetAngle - current);
}

export function easeOutQuart(t: number): number {
  return 1 - Math.pow(1 - t, 4);
}

function pointAt(angleDeg: number, r: number): [number, number] {
  const rad = (angleDeg * Math.PI) / 180;
  return [WHEEL_CENTER + r * Math.sin(rad), WHEEL_CENTER - r * Math.cos(rad)];
}

const fmt = (v: number) => Number(v.toFixed(2));

export function sectorPath(i: number, n: number): string {
  const size = 360 / n;
  const [x1, y1] = pointAt(i * size, WHEEL_RADIUS);
  const [x2, y2] = pointAt((i + 1) * size, WHEEL_RADIUS);
  const largeArc = size > 180 ? 1 : 0;
  return `M${WHEEL_CENTER} ${WHEEL_CENTER} L${fmt(x1)} ${fmt(y1)} A${WHEEL_RADIUS} ${WHEEL_RADIUS} 0 ${largeArc} 1 ${fmt(x2)} ${fmt(y2)} Z`;
}

export function sectorColor(i: number, n: number): string {
  const len = SECTOR_COLORS.length;
  // last sector would repeat the first one's color when n ≡ 1 (mod len)
  if (n > 1 && i === n - 1 && i % len === 0) return SECTOR_COLORS[len / 2];
  return SECTOR_COLORS[i % len];
}

export function labelLayout(n: number): { fontSize: number; maxChars: number } {
  const fontSize = Math.max(9, Math.min(22, Math.round(26 - n * 0.7)));
  const maxChars = Math.floor((WHEEL_RADIUS * 0.66) / (fontSize * 0.58));
  return { fontSize, maxChars };
}

export function truncateLabel(name: string, maxChars: number): string {
  return name.length > maxChars ? `${name.slice(0, maxChars - 1)}…` : name;
}

// Text runs along the sector's bisector, ending near the rim. On the left
// half it is rotated another 180° so it never reads upside down.
export function labelPlacement(i: number, n: number): { x: number; anchor: 'start' | 'end'; transform: string } {
  const mid = (i + 0.5) * (360 / n);
  const rimX = WHEEL_RADIUS * 0.9;
  if (mid <= 180) {
    return { x: WHEEL_CENTER + rimX, anchor: 'end', transform: `rotate(${fmt(mid - 90)} ${WHEEL_CENTER} ${WHEEL_CENTER})` };
  }
  return { x: WHEEL_CENTER - rimX, anchor: 'start', transform: `rotate(${fmt(mid + 90)} ${WHEEL_CENTER} ${WHEEL_CENTER})` };
}
```

```ts
import type { Rng } from '../../lib/random';

export type Level = 1 | 2 | 3;
export const LEVELS: Level[] = [1, 2, 3];
export type CardKind = 'question' | 'action';

export interface Card {
  id: string;
  level: Level;
  kind: CardKind;
  text: string;
}

interface PickOptions {
  level: Level;
  usedIds: string[];
  seenIds: ReadonlySet<string>;
  actionRatio: number;
  rng: Rng;
}

// Priority: this level → not used in this game (reset level when exhausted)
// → wanted kind (by actionRatio, else any) → not seen in earlier games.
export function pickCard(cards: Card[], { level, usedIds, seenIds, actionRatio, rng }: PickOptions): { card: Card; usedIds: string[] } {
  const levelCards = cards.filter((c) => c.level === level);
  if (levelCards.length === 0) throw new Error(`No cards for level ${level}`);

  let used = usedIds;
  let pool = levelCards.filter((c) => !used.includes(c.id));
  if (pool.length === 0) {
    const levelIds = new Set(levelCards.map((c) => c.id));
    used = used.filter((id) => !levelIds.has(id));
    pool = levelCards;
  }

  const kind: CardKind = rng() < actionRatio ? 'action' : 'question';
  const ofKind = pool.filter((c) => c.kind === kind);
  const kindPool = ofKind.length > 0 ? ofKind : pool;
  const fresh = kindPool.filter((c) => !seenIds.has(c.id));
  const finalPool = fresh.length > 0 ? fresh : kindPool;

  const card = finalPool[Math.floor(rng() * finalPool.length)];
  return { card, usedIds: [...used, card.id] };
}

export function fillTemplate(text: string, asker: string, answerer: string): string {
  return text.replaceAll('{asker}', asker).replaceAll('{answerer}', answerer);
}
```

```ts
import type { Level } from './deck';
import { normalizeDeg } from './geometry';
import type { Turn } from './turns';

export type SpinnerPhase = 'ready' | 'spinning' | 'card' | 'roundEnd';

export interface SpinnerConfig {
  spinDurationSec: number;
  actionRatio: number;
}

export interface SpinnerState {
  players: string[];
  config: SpinnerConfig;
  level: Level;
  turns: Turn[];
  turnIndex: number;
  phase: SpinnerPhase;
  rotation: number;
  cardId: string | null;
  usedIds: string[];
}

export type SpinnerAction =
  | { type: 'spin'; rotation: number; cardId: string; usedIds: string[] }
  | { type: 'spinDone' }
  | { type: 'cardDone' }
  | { type: 'startRound'; level: Level; turns: Turn[] };

export function createSpinnerGame(players: string[], config: SpinnerConfig, turns: Turn[]): SpinnerState {
  return { players, config, level: 1, turns, turnIndex: 0, phase: 'ready', rotation: 0, cardId: null, usedIds: [] };
}

export function currentTurn(state: SpinnerState): Turn {
  return state.turns[state.turnIndex];
}

export function spinnerReducer(state: SpinnerState, action: SpinnerAction): SpinnerState {
  switch (action.type) {
    case 'spin':
      if (state.phase !== 'ready') return state;
      return { ...state, phase: 'spinning', rotation: action.rotation, cardId: action.cardId, usedIds: action.usedIds };
    case 'spinDone':
      if (state.phase !== 'spinning') return state;
      return { ...state, phase: 'card', rotation: normalizeDeg(state.rotation) };
    case 'cardDone':
      if (state.phase !== 'card') return state;
      if (state.turnIndex + 1 >= state.turns.length) return { ...state, phase: 'roundEnd', cardId: null };
      return { ...state, phase: 'ready', turnIndex: state.turnIndex + 1, cardId: null };
    case 'startRound':
      if (state.phase !== 'ready' && state.phase !== 'roundEnd') return state;
      return { ...state, phase: 'ready', level: action.level, turns: action.turns, turnIndex: 0, cardId: null };
  }
}

export function restoreSpinnerGame(raw: unknown): SpinnerState | null {
  if (!raw || typeof raw !== 'object') return null;
  const s = raw as SpinnerState;
  if (!Array.isArray(s.players) || s.players.length < 2) return null;
  if (!Array.isArray(s.turns) || s.turns.length !== s.players.length) return null;
  if (typeof s.turnIndex !== 'number' || !s.turns[s.turnIndex]) return null;
  if (s.phase === 'spinning') return { ...s, phase: 'card', rotation: normalizeDeg(s.rotation) };
  return s;
}
```

```ts
import { useCallback, useEffect, useRef } from 'react';
import { WHEEL_CENTER, easeOutQuart } from './geometry';

// Animates the arrow by writing the SVG transform directly each frame and
// calls onTick whenever the arrow crosses a sector border.
export function useSpin(sectorCount: number, onTick: () => void) {
  const arrowRef = useRef<SVGGElement>(null);
  const rotation = useRef(0);
  const frame = useRef<number | null>(null);
  const tick = useRef(onTick);
  tick.current = onTick;

  const setRotation = useCallback((deg: number) => {
    rotation.current = deg;
    arrowRef.current?.setAttribute('transform', `rotate(${deg} ${WHEEL_CENTER} ${WHEEL_CENTER})`);
  }, []);

  useEffect(() => () => {
    if (frame.current !== null) cancelAnimationFrame(frame.current);
  }, []);

  const spinTo = useCallback(
    (target: number, durationMs: number) =>
      new Promise<void>((resolve) => {
        const from = rotation.current;
        const size = 360 / sectorCount;
        let lastSector = Math.floor(from / size);
        const start = performance.now();
        const step = (now: number) => {
          const t = Math.min(1, (now - start) / durationMs);
          const deg = from + (target - from) * easeOutQuart(t);
          setRotation(deg);
          const sector = Math.floor(deg / size);
          if (sector !== lastSector) {
            lastSector = sector;
            tick.current();
          }
          if (t < 1) frame.current = requestAnimationFrame(step);
          else {
            frame.current = null;
            resolve();
          }
        };
        frame.current = requestAnimationFrame(step);
      }),
    [sectorCount, setRotation],
  );

  return { arrowRef, spinTo, setRotation };
}
```

```tsx
function SpinnerGame({ initial }: { initial: SpinnerState }) {
  const { navigate, back } = useNav();
  const { settings } = useSettings();
  const fx = useFeedback();
  const [state, dispatch] = useReducer(spinnerReducer, initial);
  const [pendingLevel, setPendingLevel] = useState<Level | null>(null);
  const [confirmExit, setConfirmExit] = useState(false);
  const busy = useRef(false);
  const { arrowRef, spinTo, setRotation } = useSpin(state.players.length, () => fx.sfx('tick'));

  useWakeLock(settings.keepAwake);

  useEffect(() => {
    saveJSON(KEYS.spinnerGame, state);
  }, [state]);

  useEffect(() => {
    setRotation(initial.rotation);
  }, [initial.rotation, setRotation]);

  const turn = currentTurn(state);
  const asker = state.players[turn.asker];
  const answerer = state.players[turn.answerer];
  const card = state.cardId ? SPINNER_CARDS.find((c) => c.id === state.cardId) ?? null : null;

  const spin = async () => {
    if (state.phase !== 'ready' || busy.current) return;
    busy.current = true;
    const seen = loadJSON<string[]>(KEYS.spinnerSeen, []);
    const { card: next, usedIds } = pickCard(SPINNER_CARDS, {
      level: state.level,
      usedIds: state.usedIds,
      seenIds: new Set(seen),
      actionRatio: state.config.actionRatio,
      rng: Math.random,
    });
    const extraTurns = 4 + Math.floor(Math.random() * 2);

    setRotation(normalizeDeg(target));
    saveJSON(KEYS.spinnerSeen, [...seen, next.id]);
    fx.sfx('stop');
    fx.sfx('card');
    fx.vibrate(60);
    dispatch({ type: 'spinDone' });
    busy.current = false;
  };

    dispatch({ type: 'startRound', level, turns: buildRoundTurns(state.players.length, Math.random) });

    navigate('menu');

              disabled={state.phase !== 'ready'}

              {level}
            </button>
          ))}
        </div>
        <button type="button" className="icon-btn" aria-label="Завершить" onClick={() => setConfirmExit(true)}>✕</button>
      </header>

      <p className="spinner-game__level">
        Раунд {state.level}: {LEVEL_TITLES[state.level]} · ход {state.turnIndex + 1} из {state.turns.length}
      </p>
      <p className="spinner-game__turn">
        Крутит: <b>{asker}</b>
      </p>

      <Wheel
        players={state.players}
        activeIndex={turn.asker}
        arrowRef={arrowRef}
        disabled={state.phase !== 'ready'}
        onSpin={spin}

      <p className="muted center">{state.phase === 'ready' ? `${asker}, жми на центр круга` : ' '}</p>

      <Modal
        open={state.phase === 'card' && card !== null}
        title={card?.kind === 'action' ? 'Действие' : 'Вопрос'}
        actions={<Button size="lg" onClick={() => dispatch({ type: 'cardDone' })}>Готово</Button>}
      >
        <p className="spin-card__names"><b>{asker}</b> → <b>{answerer}</b></p>
        <p className="spin-card__text">{card ? fillTemplate(card.text, asker, answerer) : ''}</p>
      </Modal>

      <Modal
        open={state.phase === 'roundEnd'}
        title={`Раунд ${state.level} завершён`}
        actions={
          state.level < 3 ? (
            <>
              <Button variant="ghost" onClick={() => startRound(state.level)}>Ещё круг</Button>
              <Button onClick={() => startRound((state.level + 1) as Level)}>Раунд {state.level + 1}</Button>
            </>
          ) : (
            <>
              <Button variant="ghost" onClick={finish}>Завершить игру</Button>
              <Button onClick={() => startRound(3)}>Ещё круг</Button>
            </>
          )
        }
      >
        <p>
          Все покрутили и все ответили.{' '}
          {state.level < 3 ? `Дальше — «${LEVEL_TITLES[(state.level + 1) as Level]}».` : 'Это был самый глубокий уровень.'}
        </p>
      </Modal>

      <Modal
        open={pendingLevel !== null}
        title={`Перейти к раунду ${pendingLevel}?`}
        actions={
          <>
            <Button variant="ghost" onClick={() => setPendingLevel(null)}>Отмена</Button>
            <Button onClick={() => { if (pendingLevel) startRound(pendingLevel); setPendingLevel(null); }}>Перейти</Button>
          </>
        }
      >
        <p>Круг начнётся заново: каждый снова покрутит и ответит.</p>
      </Modal>

      <Modal
        open={confirmExit}
        title="Завершить игру?"
        actions={
          <>
            <Button variant="ghost" onClick={() => setConfirmExit(false)}>Отмена</Button>
            <Button variant="danger" onClick={finish}>Завершить игру</Button>
          </>
        }
      >
        <p>Прогресс этой партии будет удалён.</p>
      </Modal>
    </div>
  );
}
```
