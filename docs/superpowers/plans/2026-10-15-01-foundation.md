# «Ломаем Лёд» — Plan 1: Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deployable PWA shell: main menu (2 active + 2 locked games), settings screen, sound/vibration/wake-lock/music engines, shared player-list input, auto-deploy to GitHub Pages.

**Architecture:** Vite + React SPA without a router library: a tiny `NavProvider` keeps the current screen name and mirrors it into `history` so Android's back gesture works. Settings live in a React context persisted to `localStorage`. All game-independent infrastructure (storage, feedback, UI kit) lives here; games plug in by replacing entries in a `SCREENS` registry.

**Tech Stack:** Node 20, Vite 5.4, React 18.3, TypeScript 5.6, Vitest 2.1 + Testing Library + jsdom, vite-plugin-pwa 0.20, @vite-pwa/assets-generator, @fontsource (Unbounded, Manrope), GitHub Actions + Pages.

**Spec:** `docs/spec.md`

**Follow-up plans:** `2026-10-15-02-spinner.md` (Крутилочка), `2026-10-15-03-hat.md` (Шляпа). They consume interfaces defined here.

## Global Constraints

- Target device: Xiaomi 15 Ultra, Google Chrome (Android); portrait only.
- UI language: Russian only. All user-visible strings in Russian.
- Content: no 18+ (no sex, alcohol, explicit topics).
- Hosting: GitHub Pages, repo `drkiray/lomaem-led` (public), URL `https://drkiray.github.io/lomaem-led/`, Vite `base: '/lomaem-led/'`.
- Deploy: GitHub Actions on every push to `main`.
- Offline after first load (service worker precaches all assets incl. fonts and music).
- Persistence: `localStorage` only, every key prefixed `ll.`; every read/write wrapped in try/catch, corrupted data falls back to defaults.
- Visual style: «ледяной неон» — dark background, ice-blue/turquoise accents, glow; cracking-ice transition between screens.
- Defaults: SFX on (0.8), music off (0), vibration on, keep-awake on.
- Git commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Corrupted / foreign JSON in `localStorage` (or storage throwing) → app still starts with defaults (test in Task 2).
2. Android back gesture/button inside the app → returns to previous screen instead of closing the PWA (test in Task 3).
3. Chrome blocks audio before the first user gesture / `AudioContext` missing → no crash, sound starts after first tap (test in Task 5).
4. `public/music/bg.mp3` missing or `play()` rejected → silent, no unhandled rejection (test in Task 5).
5. Wake Lock unavailable or rejected (battery saver) → no crash; lock re-acquired after returning to the tab (test in Task 5).

`src/lib/storage.ts`:
```ts
const PREFIX = 'll.';

export const KEYS = {
  settings: 'settings',
  lastPlayers: 'lastPlayers',
  spinnerGame: 'spinner.game',
  spinnerSeen: 'spinner.seen',
  hatGame: 'hat.game',
} as const;

export function loadJSON<T>(key: string, fallback: T): T {
  try {
    const raw = localStorage.getItem(PREFIX + key);
    return raw === null ? fallback : (JSON.parse(raw) as T);
  } catch {
    return fallback;
  }
}

export function saveJSON(key: string, value: unknown): void {
  try {
    localStorage.setItem(PREFIX + key, JSON.stringify(value));
  } catch {
    // storage full or blocked — the app keeps working in memory
  }
}

export function removeKey(key: string): void {
  try {
    localStorage.removeItem(PREFIX + key);
  } catch {
    // ignore
  }
}
```

```ts
export type WordDifficulty = 'easy' | 'medium' | 'hard';
export type DifficultySetting = WordDifficulty | 'mix';
export type TurnSeconds = 30 | 45 | 60 | 90;
export type WordCount = 30 | 40 | 60;

export interface SpinnerSettings {
  spinDurationSec: number;
  actionRatio: number;
}

export interface HatSettings {
  turnSeconds: TurnSeconds;
  skipPenalty: boolean;
  lastWordSeconds: number;
  difficulty: DifficultySetting;
  wordCount: WordCount;
  wordsPerPlayer: number;
}

export interface Settings {
  sfxVolume: number;
  musicVolume: number;
  vibration: boolean;
  keepAwake: boolean;
  spinner: SpinnerSettings;
  hat: HatSettings;
}

export type SettingsPatch = Partial<Omit<Settings, 'spinner' | 'hat'>> & {
  spinner?: Partial<SpinnerSettings>;
  hat?: Partial<HatSettings>;
};

export const DEFAULT_SETTINGS: Settings = {
  sfxVolume: 0.8,
  musicVolume: 0,
  vibration: true,
  keepAwake: true,
  spinner: { spinDurationSec: 4, actionRatio: 0.3 },
  hat: {
    turnSeconds: 60,
    skipPenalty: false,
    lastWordSeconds: 5,
    difficulty: 'mix',
    wordCount: 40,
    wordsPerPlayer: 5,
  },
};

export function applyPatch(base: Settings, patch: SettingsPatch): Settings {
  return {
    ...base,
    ...patch,
    spinner: { ...base.spinner, ...patch.spinner },
    hat: { ...base.hat, ...patch.hat },
  };
}

export function mergeSettings(stored: unknown): Settings {
  if (!stored || typeof stored !== 'object' || Array.isArray(stored)) return DEFAULT_SETTINGS;
  return applyPatch(DEFAULT_SETTINGS, stored as SettingsPatch);
}
```

`src/settings/SettingsContext.tsx`:
```tsx
import { createContext, useCallback, useContext, useEffect, useMemo, useState, type ReactNode } from 'react';
import { KEYS, loadJSON, saveJSON } from '../lib/storage';
import { DEFAULT_SETTINGS, applyPatch, mergeSettings, type Settings, type SettingsPatch } from './settings';

interface SettingsApi {
  settings: Settings;
  update: (patch: SettingsPatch) => void;
  reset: () => void;
}

const SettingsContext = createContext<SettingsApi | null>(null);

export function SettingsProvider({ children }: { children: ReactNode }) {
  const [settings, setSettings] = useState<Settings>(() => mergeSettings(loadJSON<unknown>(KEYS.settings, null)));

  useEffect(() => {
    saveJSON(KEYS.settings, settings);
  }, [settings]);

  const update = useCallback((patch: SettingsPatch) => setSettings((s) => applyPatch(s, patch)), []);
  const reset = useCallback(() => setSettings(DEFAULT_SETTINGS), []);
  const value = useMemo(() => ({ settings, update, reset }), [settings, update, reset]);

  return <SettingsContext.Provider value={value}>{children}</SettingsContext.Provider>;
}

export function useSettings(): SettingsApi {
  const value = useContext(SettingsContext);
  if (!value) throw new Error('useSettings must be used inside SettingsProvider');
  return value;
}
```

```tsx
import { createContext, useCallback, useContext, useEffect, useMemo, useState, type ReactNode } from 'react';

export type RouteName = 'menu' | 'settings' | 'spinner-setup' | 'spinner-game' | 'hat-setup' | 'hat-game';

export interface Nav {
  route: RouteName;
  navigate: (route: RouteName, opts?: { replace?: boolean }) => void;
  back: () => void;
}

export const NavContext = createContext<Nav | null>(null);

export function useNav(): Nav {
  const value = useContext(NavContext);
  if (!value) throw new Error('useNav must be used inside NavProvider');
  return value;
}

// Each screen change is mirrored into window.history so the Android back
// gesture moves between screens instead of closing the PWA.
export function NavProvider({ children }: { children: ReactNode }) {
  const [route, setRoute] = useState<RouteName>('menu');

  useEffect(() => {
    window.history.replaceState({ route: 'menu' }, '');
    const onPop = (e: PopStateEvent) => {
      const state = e.state as { route?: RouteName } | null;
      setRoute(state?.route ?? 'menu');
    };
    window.addEventListener('popstate', onPop);
    return () => window.removeEventListener('popstate', onPop);
  }, []);

  const navigate = useCallback((next: RouteName, opts?: { replace?: boolean }) => {
    if (opts?.replace) window.history.replaceState({ route: next }, '');
    else window.history.pushState({ route: next }, '');
    setRoute(next);
  }, []);

  const back = useCallback(() => window.history.back(), []);
  const value = useMemo(() => ({ route, navigate, back }), [route, navigate, back]);

  return <NavContext.Provider value={value}>{children}</NavContext.Provider>;
}
```

```ts
export type SfxName = 'tick' | 'stop' | 'card' | 'correct' | 'skip' | 'timeUp' | 'countdown' | 'tap';

interface Tone {
  freq: number;
  dur: number;
  type?: OscillatorType;
  delay?: number;
  gain?: number;
  slideTo?: number;
}

export const SFX_RECIPES: Record<SfxName, Tone[]> = {
  tick: [{ freq: 1800, dur: 0.025, type: 'square', gain: 0.2 }],
  stop: [
    { freq: 660, dur: 0.12, type: 'triangle' },
    { freq: 990, dur: 0.18, type: 'triangle', delay: 0.1 },
  ],
  card: [{ freq: 520, dur: 0.25, type: 'sine', slideTo: 880 }],
  correct: [
    { freq: 784, dur: 0.1, type: 'triangle' },
    { freq: 1047, dur: 0.16, type: 'triangle', delay: 0.09 },
  ],
  skip: [{ freq: 330, dur: 0.18, type: 'sawtooth', slideTo: 220, gain: 0.35 }],
  timeUp: [
    { freq: 880, dur: 0.2, type: 'square', gain: 0.45 },
    { freq: 880, dur: 0.2, type: 'square', gain: 0.45, delay: 0.3 },
    { freq: 660, dur: 0.5, type: 'square', gain: 0.45, delay: 0.6 },
  ],
  countdown: [{ freq: 600, dur: 0.12, type: 'sine' }],
  tap: [{ freq: 420, dur: 0.05, type: 'sine', gain: 0.5 }],
};

let ctx: AudioContext | null = null;

function getContext(): AudioContext | null {
  if (!ctx) {
    const Ctor = window.AudioContext ?? (window as unknown as { webkitAudioContext?: typeof AudioContext }).webkitAudioContext;
    if (!Ctor) return null;
    ctx = new Ctor();
  }
  // Chrome starts the context suspended until a user gesture; every sfx is triggered by one.
  if (ctx.state === 'suspended') void ctx.resume();
  return ctx;
}

export function playSfx(name: SfxName, volume: number): void {
  if (volume <= 0) return;
  try {
    const audio = getContext();
    if (!audio) return;
    const now = audio.currentTime;
    for (const tone of SFX_RECIPES[name]) {
      const start = now + (tone.delay ?? 0);
      const end = start + tone.dur;
      const osc = audio.createOscillator();
      const gain = audio.createGain();
      osc.type = tone.type ?? 'sine';
      osc.frequency.setValueAtTime(tone.freq, start);
      if (tone.slideTo) osc.frequency.exponentialRampToValueAtTime(tone.slideTo, end);
      const peak = Math.max(0.0001, volume * (tone.gain ?? 0.6) * 0.5);
      gain.gain.setValueAtTime(0.0001, start);
      gain.gain.linearRampToValueAtTime(peak, start + 0.01);
      gain.gain.exponentialRampToValueAtTime(0.0001, end);
      osc.connect(gain);
      gain.connect(audio.destination);
      osc.start(start);
      osc.stop(end + 0.02);
    }
  } catch {
    // audio is decorative — never break the game over it
  }
}

export function resetSfxForTests(): void {
  ctx = null;
}
```

```ts
export function setMusicVolume(volume: number): void {
  if (volume <= 0) {
    audio?.pause();
    return;
  }
  try {
    if (!audio) {
      audio = new Audio(MUSIC_URL);
      audio.loop = true;
    }

    if (audio.paused) {

      // Rejected when autoplay is blocked (retried on next tap) or the file is missing.
      if (played) played.catch(() => {});
    }
  } catch {
```

```ts
import { useEffect } from 'react';

// Keeps the screen on while `active`. The browser drops the lock when the tab
// is hidden, so it is re-requested whenever the page becomes visible again.
export function useWakeLock(active: boolean): void {
  useEffect(() => {
    if (!active || !navigator.wakeLock) return;
    let sentinel: WakeLockSentinel | null = null;
    let disposed = false;

    const request = async () => {
      try {
        const lock = await navigator.wakeLock.request('screen');
        if (disposed) void lock.release().catch(() => {});
        else sentinel = lock;
      } catch {
        // denied (battery saver) — nothing to do
      }
    };
    const onVisibility = () => {
      if (document.visibilityState === 'visible') void request();
    };

    void request();
    document.addEventListener('visibilitychange', onVisibility);
    return () => {
      disposed = true;
      document.removeEventListener('visibilitychange', onVisibility);
      if (sentinel) void sentinel.release().catch(() => {});
    };
  }, [active]);
}
```

```ts
export function plural(n: number, one: string, few: string, many: string): string {
  const mod10 = n % 10;
  const mod100 = n % 100;
  if (mod10 === 1 && mod100 !== 11) return one;
  if (mod10 >= 2 && mod10 <= 4 && (mod100 < 12 || mod100 > 14)) return few;
  return many;
}
```

```ts
import { plural } from '../lib/plural';
import { KEYS, loadJSON, saveJSON } from '../lib/storage';

export function cleanPlayers(raw: string[]): string[] {
  return raw.map((name) => name.trim().replace(/\s+/g, ' ')).filter(Boolean);
}

export function validatePlayers(raw: string[], min: number): string | null {
  const names = cleanPlayers(raw);
  if (names.length < min) return `Нужно минимум ${min} ${plural(min, 'игрок', 'игрока', 'игроков')}`;
  const seen = new Set<string>();
  for (const name of names) {
    const key = name.toLowerCase();
    if (seen.has(key)) return `Имя «${name}» повторяется`;
    seen.add(key);
  }
  return null;
}

export function loadLastPlayers(): string[] {
  const value = loadJSON<unknown>(KEYS.lastPlayers, []);
  return Array.isArray(value) ? value.filter((v): v is string => typeof v === 'string') : [];
}

export function rememberPlayers(names: string[]): void {
  saveJSON(KEYS.lastPlayers, names);
}
```

`src/players/PlayerListInput.tsx`:
```tsx
import { useEffect, useMemo, useRef, useState } from 'react';
import { Button } from '../ui/Button';
import { cleanPlayers, loadLastPlayers } from './players';

interface Props {
  players: string[];
  onChange: (players: string[]) => void;
}

export function PlayerListInput({ players, onChange }: Props) {
  const inputs = useRef<(HTMLInputElement | null)[]>([]);
  const [focusIndex, setFocusIndex] = useState<number | null>(null);
  const last = useMemo(loadLastPlayers, []);

  useEffect(() => {
    if (focusIndex === null) return;
    inputs.current[focusIndex]?.focus();
    setFocusIndex(null);
  }, [focusIndex]);

  const setAt = (index: number, name: string) => onChange(players.map((p, i) => (i === index ? name : p)));
  const removeAt = (index: number) => onChange(players.filter((_, i) => i !== index));
  const add = () => {
    onChange([...players, '']);
    setFocusIndex(players.length);
  };

  return (
    <div className="players">
      {last.length > 0 && (
        <Button variant="ghost" onClick={() => onChange([...last])}>
          Как в прошлый раз ({last.length})
        </Button>
      )}
      <ol className="players__list">
        {players.map((name, i) => (
          <li key={i} className="players__row">
            <span className="players__num">{i + 1}</span>
            <input
              ref={(el) => {
                inputs.current[i] = el;
              }}
              className="input"
              value={name}
              placeholder={`Игрок ${i + 1}`}
              aria-label={`Имя игрока ${i + 1}`}
              maxLength={20}
              autoCapitalize="words"
              enterKeyHint="next"
              onChange={(e) => setAt(i, e.target.value)}
              onKeyDown={(e) => {
                if (e.key !== 'Enter') return;
                e.preventDefault();
                if (i === players.length - 1) add();
                else inputs.current[i + 1]?.focus();
              }}
            />
            <button
              type="button"
              className="icon-btn icon-btn--small"
              aria-label={`Удалить игрока ${i + 1}`}
              onClick={() => removeAt(i)}
            >
              ✕
            </button>
          </li>
        ))}
      </ol>
      <Button variant="ghost" onClick={add}>+ Добавить игрока</Button>
      <p className="muted">Игроков: {cleanPlayers(players).length}</p>
    </div>
  );
}
```
