# «Ломаем Лёд» — спецификация v1

Мобильное браузерное приложение с патигеймами для вечеринок и дней рождения.
Первая итерация оптимизирована под Xiaomi 15 Ultra, Google Chrome (Android).

## 1. Платформа и инфраструктура

| Параметр | Решение |
|---|---|
| Тип | PWA (устанавливается на главный экран, работает офлайн после первой загрузки) |
| Стек | Vite + React + TypeScript + `vite-plugin-pwa` |
| Хостинг | GitHub Pages, репозиторий `drkiray/lomaem-led` (публичный) |
| URL | `https://drkiray.github.io/lomaem-led/` |
| Деплой | GitHub Actions: сборка и публикация на каждый push в `main` |
| Ориентация | Только портретная (`orientation: portrait` в манифесте) |
| Экран | Wake Lock API — экран не гаснет во время игры (отключаемо) |
| Сохранение | Состояние текущей партии и настройки — в `localStorage`; при открытии — «Продолжить игру?» |
| Язык | Только русский |
| Контент | Вопросы и слова — в отдельных TS-модулях (`src/content/`), не в компонентах |

## 2. Визуальный стиль

- «Ледяной неон»: тёмный фон, ледяные голубые/бирюзовые акценты, свечение.
- Переходы между экранами — эффект трескающегося льда.
- Яркая палитра для секторов колеса и цветов команд, хорошо читаемая на тёмном фоне.
- Крупные тап-зоны, рассчитано на использование одной рукой и передачу телефона.

## 3. Главное меню

- Логотип/название «Ломаем Лёд».
- Карточки игр:
  - **Крутилочка** — активна.
  - **Шляпа** — активна.
  - **Правда или действие** — заблокирована (замок, подпись «Скоро»).
  - **Нетворкинг** — заблокирована (замок, подпись «Скоро»).
- Иконка шестерёнки → экран «Настройки».
- Если есть незавершённая партия — баннер «Продолжить игру?».

## 4. Настройки

Глобальные:
- Громкость звуковых эффектов (ползунок, по умолчанию вкл).
- Громкость музыки (ползунок, по умолчанию 0 / выкл).
- Вибрация вкл/выкл (по умолчанию вкл).
- Не гасить экран во время игры вкл/выкл (по умолчанию вкл).
- Сбросить все настройки.

Дефолты «Крутилочки»:
- Длительность кручения стрелки.
- Доля действий среди карточек (по умолчанию 30%).
- Сбросить историю показанных вопросов.

Дефолты «Шляпы»:
- Длительность хода: 30 / 45 / 60 / 90 сек (по умолчанию 60).
- Штраф за пропуск (−1) вкл/выкл (по умолчанию выкл).
- Время на последнее слово (по умолчанию 5 сек).
- Сложность словаря: лёгкие / средние / сложные / микс.

Дефолты можно переопределить на экране подготовки конкретной партии.

## 5. Звук и музыка

- Звуковые эффекты синтезируются через Web Audio API: тик стрелки при вращении (замедляющийся), остановка, появление карточки, «угадали», «пропуск», сигнал конца таймера, обратный отсчёт.
- Музыка: 1–2 royalty-free трека (Pixabay Music) для фона, mp3 ~1–2 МБ, кэшируются service worker'ом. По умолчанию выключена.
- Вибрация (Vibration API) дублирует ключевые события: остановка стрелки, конец таймера.

## 6. Игра «Крутилочка»

### 6.1 Подготовка партии
- Ввод имён игроков (обязательно, каждую партию заново; кнопка «как в прошлый раз» подставляет прошлый список).
- Количество игроков — без жёсткого лимита, мягкий потолок ~30. Минимум 2.
- Переопределение настроек партии (длительность кручения, доля действий).
- Кнопка «Начать».

### 6.2 Экран игры
- Круг, разбитый на N секторов (N = число игроков), у каждого свой цвет из палитры (по кругу при нехватке цветов).
- Имена в секторах; при росте N шрифт уменьшается, при узких секторах имя поворачивается вдоль радиуса.
- В центре — стрелка, совмещённая с кнопкой кручения.
- Сверху: индикатор раунда («Раунд 1 / 2 / 3») и «Крутит: **Имя**».
- Сектор текущего крутящего подсвечивается и пульсирует.

### 6.3 Ход
1. Телефон у крутящего (его сектор подсвечен).
2. Тап по центру → стрелка вращается с замедлением (по умолчанию 3–5 сек), тикает звук.
3. Стрелка останавливается на секторе отвечающего.
4. Всплывает карточка: «**Крутящий** → **Отвечающий**» + текст вопроса или действия.
5. Крутящий зачитывает, отвечающий отвечает/выполняет.
6. Кнопка «Готово» → следующий ход, подсвечивается новый крутящий.

### 6.4 Алгоритм очерёдности
- В начале раунда генерируется случайный **дерранжемент** игроков (перестановка без неподвижных точек): каждый игрок ровно один раз крутит и ровно один раз отвечает; никто не отвечает сам себе.
- Порядок, в котором игроки крутят, — случайный (не по часовой стрелке).
- Конечный угол стрелки вычисляется заранее: стрелка останавливается в случайной точке внутри сектора назначенного отвечающего. Визуально — обычный рандом.
- При 2 игроках: A спрашивает B, B спрашивает A.

### 6.5 Раунды
- Раунд = N ходов (все покрутили, все ответили).
- По окончании раунда: «Раунд X завершён» → «Перейти к раунду X+1» или «Ещё круг» (новый дерранжемент, тот же уровень).
- После раунда 3: «Ещё круг» или «Завершить игру».
- Ведущий может досрочно переключить раунд через индикатор раунда.

### 6.6 Контент
- 3 уровня:
  1. **Знакомство** — лёгкие вопросы для незнакомых людей.
  2. **Глубже** — личные, но комфортные.
  3. **Психология** — глубокие, уязвимые, рефлексивные.
- Без 18+ (секс, алкоголь, откровенные темы исключены).
- ~40 карточек на уровень, ~120 всего.
- Соотношение вопрос/действие ≈ 70/30 (настраивается).
- Действия адресуются конкретным игрокам по имени (крутящему или отвечающему), без привязки к рассадке («сосед слева» не используется).
- Шаблоны с подстановкой имён: `{asker}`, `{answerer}`.
- Внутри партии вопросы не повторяются, пока колода уровня не исчерпана.
- Между партиями приложение помнит показанные карточки (`localStorage`) и в первую очередь выдаёт непоказанные.

## 7. Игра «Шляпа»

### 7.1 Подготовка партии
1. **Игроки**: ввод имён (кнопка «как в прошлый раз»).
2. **Команды**: выбор числа команд (минимум 2, минимум 2 человека в команде).
   - «Перемешать» — случайное распределение.
   - Ручная правка: тап по игроку переносит его в другую команду.
   - Каждой команде — цвет и автоназвание («Пингвины», «Кактусы» и т.п.), можно переименовать.
3. **Слова** — режим:
   - **Словарь**: выбрать количество (30 / 40 / 60) и сложность.
   - **Свои слова**: каждый игрок по очереди тайно вводит K слов (по умолчанию 5), экран скрывается между игроками.
   - **Микс**: свои слова + добор из словаря до нужного количества.
4. **Настройки партии**: таймер, штраф за пропуск, время на последнее слово.

### 7.2 Раунды
Все три раунда играются **одним и тем же набором слов**; после раунда все слова возвращаются в шляпу.
1. **Объясняем словами** (нельзя однокоренные).
2. **Показываем жестами** (без звуков).
3. **Одно слово** — объяснение ровно одним словом.

Перед каждым раундом — экран с правилами раунда.

### 7.3 Очерёдность
- Команды ходят по кругу.
- Внутри команды объясняющий ротируется каждый ход команды; угадывают все остальные члены команды.

### 7.4 Ход
1. Экран «Объясняет **Имя** (Команда)» → кнопка «Старт» → отсчёт 3-2-1.
2. Показывается слово; таймер идёт.
3. Кнопки: большая «Угадали» (+1, следующее слово) и «Пропуск» (слово возвращается в шляпу; −1 если включён штраф).
4. Конец времени: звук + вибрация; на текущее слово даётся последняя попытка (по умолчанию 5 сек) — «Угадали» / «Не успели».
5. **Итоги хода**: список слов хода с отметками, можно исправить ошибочные нажатия → «Передать ход».

### 7.5 Конец раунда и игры
- Шляпа опустела → экран счёта команд → правила следующего раунда.
- Если слова закончились посреди хода, остаток времени переносится: та же команда/объясняющий начинает следующий раунд с оставшимся временем.
- После раунда 3: финальный счёт, победитель, «Сыграть ещё» (те же команды) / «В меню».

### 7.6 Словарь
- ~500 существительных и понятий, размеченных по сложности (лёгкие / средние / сложные).
- Без 18+.

## 8. Вне скоупа v1

- Игры «Правда или действие» и «Нетворкинг» (только заглушки в меню).
- 18+ режим «Крутилочки».
- Мультиязычность.
- Мультиустройственная игра / онлайн.
- Оптимизация под другие устройства и браузеры (должно работать, но не тестируется целенаправленно).

## 9. Этапы реализации (черновик)

1. Каркас: Vite + React + TS, PWA, деплой на GitHub Pages.
2. Главное меню, настройки, звуковой движок, стиль.
3. «Крутилочка»: колесо, алгоритм, раунды.
4. «Шляпа»: команды, слова, ходы, раунды, счёт.
5. Контент: вопросы (~120) и словарь (~500).
6. Музыка, полировка анимаций, тест на Xiaomi 15 Ultra.
